# 3D model credits

The following unmodified GLB models are sourced from NASA's NASA-3D-Resources repository. Models are used as illustrative mission configurations, not as real-time views or exact reconstructions. The Apollo lunar module shows the historic landing configuration; the descent stage is the part that remained on the Moon.

- `apollo-lunar-module.glb`: [Apollo Lunar Module](https://github.com/nasa/NASA-3D-Resources/blob/master/3D%20Models/Apollo%20Lunar%20Module/Apollo%20Lunar%20Module.glb), NASA 3D Resources, Git blob `74b7b99a60f9903a0592fd763ed14482204e24d9`.
- `insight.glb`: [InSight Cruise Lander (arm deployed)](https://github.com/nasa/NASA-3D-Resources/blob/master/3D%20Models/InSight%20Cruise%20Lander/InSight%20Cruise%20Lander%20%28arm%20deployed%29.glb), NASA 3D Resources, Git blob `9356e2adfa5a6b6ec118f6e5bf92a1d65d6395fc`.
- `ingenuity.glb`: [Ingenuity Mars Helicopter](https://github.com/nasa/NASA-3D-Resources/blob/master/3D%20Models/Ingenuity%20Mars%20Helicopter/Ingenuity%20Mars%20Helicopter.glb), NASA 3D Resources, Git blob `62dbbac41bed72d2300b036fcfe7be6994d12622`.

Acquired 15 November 2026 via the GitHub API; the original binary data is unchanged. The NASA repository describes the resources as free and without copyright; NASA's [media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) apply. NASA does not endorse this project. Runtime framing normalizes each model's scale and position.

The Draco decoder files in `/draco/` are distributed with Three.js, from Google's Draco project (Apache 2.0): https://github.com/google/draco .
